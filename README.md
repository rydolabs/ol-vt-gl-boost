# OL VT GL Boost

Optimized OpenLayers Vector Tile WebGL rendering pipeline (CPU-first stable path).

**Status:** experimental integration, not production approved. Worker is disabled by default. R48 CPU line-join correctness fallback is retained.

This repository is being migrated from [the M5 validation work](https://github.com/nssang00/chatgpt-write-test/pull/23). Code and tests will be staged on a review branch; the default branch is intentionally kept minimal until regression and physical RTX CI results have been reviewed.
