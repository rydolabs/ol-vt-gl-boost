WebGL Vector Tiles — OpenLayers vs Boost

Inspired by OpenLayers' WebGL Vector Tiles example. Both modes use the same local MapLibre OpenMapTiles MVT bytes, literal colors/widths, pinned OL 10.10.0, map size and view. The official example uses Mapbox-hosted MVT and a much richer rule/text style, so these numbers must not be presented as an exact reproduction of its style workload.

Measurement excludes PBF download; first complete frame starts before attaching the map. Pan timings are main-thread renderSync() submission, not GPU frame time or sustained FPS. Do not compare two simultaneously running maps: select a renderer or run automated ABBA.
